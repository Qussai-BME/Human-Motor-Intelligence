# Q1 Evidence Expansion Master Audit — V2 Recovery R3

## Status Statement

This is an **R3 superseding integration audit**, not a modification of any frozen V1, V1.1, R1, or R2 result. It incorporates the R3 replay-identity audit and the completed Q1 manuscript apparatus for P4–P6. It records a scientifically legitimate hard stop: the requested three-condition P6 decoder-quality analysis is **not executed** because authentic, provenance-linked replay traces are absent.

> The R2 P6 replay file is identified by its own event metadata as `source_subject=synthetic-demo` and `model_version=example-decoder-v1`. It is an integration fixture, not an authenticated worst/tiny-CNN trace.

## R3 Corrections and Non-Retroactivity

The historical R2 filename `p6_real_replay_initial_state_repeats_r2` and the R2 audit wording remain preserved as part of the frozen record. R3 corrects the **interpretation**, rather than editing the historical artefacts: future documents must call the input an example/integration fixture and must link to the hard-stop record. No R2 values are reused as a decoder-quality condition.

## Evidence Quality and Reproducibility Controls

P4 and P5 have manifest, protocol, D1–D5 validation, subject-level outcomes, statistics, figures, and byte-identical independent reruns. P6 has source fingerprints, patch record, baseline compatibility and capability checks, 20 per-seed records, endpoint statistics, and byte-identical `run_records.json`. The R3 hard stop itself is a quality-control result: it prevented a false condition mapping before preregistration amendment, execution, or inference.

## Conditions for Reopening P6 R3

The programme can reopen P6 R3 only after the user supplies three immutable traces and a manifest mapping each trace to a declared condition. The manifest must state trace pathname, SHA-256, producing model/version/checkpoint identifier, intended decoder-quality condition, subject/source provenance, sampling/serialization details, and confirmation that each output was frozen before study execution. A `V2_PROTOCOL_AMENDMENT_RECOVERY_R2_004.md` record must then be created **before** computation. If no authentic prior condition maps validly, all three conditions must be run afresh in a new R3 namespace.

## Release Decision

The evidence is suitable for an **interim current-state integration package**. It is not suitable for a final all-complete P6 R3 release because the central P6 three-decoder requirement is blocked by absent provenance.
