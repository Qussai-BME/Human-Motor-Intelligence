# Public scripts

This directory contains supported, argument-driven utilities and analysis entry points for the current research release. Scripts that were tied to an earlier workstation layout or a superseded P6 R2 execution are preserved under `historical/` and are not part of the supported public runner surface.

For the current P6 evidence record, use the explicit runners under `p6/exploratory_r03_primary/` and `p6/exploratory_r03_rerun/`. They require the external PhysioNet data root and, for simulator replay, an explicit MyoSim root.

The frozen P1-P5 result packages remain evidence archives. Regenerating their historical results is not implied by the presence of analysis utilities in this directory.
