# Security

This repository is a research archive and local research software project. It is not a clinical device, hosted service, or security-sensitive production application.

Do not submit participant-identifying data, credentials, private datasets, or proprietary simulator sources through public issues or pull requests. Raw participant recordings are intentionally excluded from the release.

For a suspected security or privacy issue in the released software, report the affected file, reproducible steps, and whether the issue exposes participant data or credentials. Do not attach private datasets to a public report.
