# Historical pre-R03-reexecution snapshot

These files document the state of the programme before the authenticated R03 motor-execution traces were available. Their statements that P6 R3 was blocked are historical records, not the current release status. They are preserved for provenance and audit history.

The current authoritative P6 record is under `p6/exploratory_r03_primary/`, `p6/exploratory_r03_rerun/`, and `papers/paper_6/`.
